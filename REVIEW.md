# Resonant Field proposal review

Resonant Field extends ROSI within ResonantOS. This is Simon's proposal for review; it does not establish upstream adoption, contributor endorsement or a released integration. Simon approved all included backgrounds.

Open `index.html` through a local static server. The prototype remains interactive, with a scoped candidate runtime in `runtime/`. Original material is review only; bundled third-party code and fonts retain their own notices.

The asset inventory records shipped-file hashes and measured image dimensions separately from historical source-master records. Reference code is pinned to public source revisions. Current technical checks are recorded in `EXPORT-CHECKS.json`; automated checks do not establish aesthetic approval or a complete assistive-technology certification.
